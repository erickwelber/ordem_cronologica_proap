Medidas DAX Prontas para o Power BI

Copie estas medidas e crie uma tabela de suporte chamada _Medidas no Power BI Desktop. Todas usam os nomes físicos exatos da sua base:

1. Valor Total Pago 
Valor Total Pago = 
SUM ( 'ordem_cronologica'[saldo_moeda_origem] )
2. Quantidade de Pagamentos (OBs Únicas) 
Qtd Pagamentos = 
DISTINCTCOUNT ( 'ordem_cronologica'[documento] )
3. Taxa de Pontualidade no Prazo (% SLA) 
% Pontualidade no Prazo = 
VAR _Total = [Qtd Pagamentos]
VAR _NoPrazo = 
    CALCULATE (
        [Qtd Pagamentos],
        KEEPFILTERS ( 'ordem_cronologica'[comrpromisso_dia_pagamento] <= 'ordem_cronologica'[compromisso_dia_vencimento] )
    )
RETURN
    DIVIDE ( _NoPrazo, _Total, 0 )
4. Lead Time Médio de Tramitação (Dias) 
Lead Time Medio Tramitacao (Dias) = 
AVERAGEX (
    'ordem_cronologica',
    VAR _Ateste = 'ordem_cronologica'[dh_dia_ateste]
    VAR _Pgto = 'ordem_cronologica'[comrpromisso_dia_pagamento]
    RETURN
        IF ( NOT ISBLANK(_Ateste) && NOT ISBLANK(_Pgto), INT(_Pgto - _Ateste) )
)
5. Valor Pago em Atraso 
Valor Pago em Atraso = 
CALCULATE (
    [Valor Total Pago],
    KEEPFILTERS ( 'ordem_cronologica'[comrpromisso_dia_pagamento] > 'ordem_cronologica'[compromisso_dia_vencimento] )
)
